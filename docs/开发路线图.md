# 开发路线图

当前优先国际版红、蓝、黄。v1.1.0-beta.1 已开放英文、法文、德文、意大利文及西班牙文 ROM 的核心存档编辑，后续通过用户反馈和针对性回归完善兼容性。

## 共用存档读写

国际版红、蓝、黄的队伍、箱子、背包与 PC 道具采用相同布局。这部分共用现有编辑和备份逻辑。兼容模式从 ROM 的数据表识别版本，已解除 v1.0.0 单一 ROM 哈希白名单的限制。 [字段对比](国际版兼容.md)

接下来优先修复用户反馈的导入、昵称、招式、道具或保存问题，并在兼容清单中记录游戏颜色、语言、修订版和实测结果。日版及绿版的适配顺序留待国际版工作之后安排。

## 地图与事件

继续将地图读取和事件规则适配到国际版红、蓝，再处理黄版地图与专属剧情。每个目标记录其使用的位、触发条件和已知副作用。存档编辑与地图事件分别标明兼容状态。

## 当前局限和反馈

v1.0.0 的完整地图功能适用于已验证的简体中文红版。其事件清单含 978 个目标，其中 416 个可单独复位。国际版测试模式已开放核心编辑，地图脚本仍在适配。箱内能力值在取出时由游戏重算，队伍手填能力值也可能在升级或进化时重算。发行包已在 Windows 11 x64 验收。

每次导入保留原档备份，用用户反馈的具体案例补充回归测试。请在兼容性问题中提供游戏颜色和语言、ROM 的 SHA-256、模拟器名称、复现步骤与报错文字。 [提交反馈](https://github.com/LFK0560/PokemonRedSaveEditor/issues/new?template=compatibility.md)
