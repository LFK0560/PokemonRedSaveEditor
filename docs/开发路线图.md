# 开发路线图

计划先适配 Game Boy 原版红版的多个语言版本，再依次适配绿版、黄版和蓝版。按实际通过验收的语言、地区和 ROM 修订版发布支持清单。

## 当前版本的局限

- **ROM 与存档**　v1.0.0 只支持 [使用说明](使用说明.md#选择-rom-和存档) 所列 SHA-256 对应的简体中文红版。它读取游戏内保存生成的 32 KiB SRAM。模拟器即时存档、其他汉化版本和跨版本存档转换均未支持。
- **事件复位**　当前 [事件清单](事件索引.csv) 的 978 个目标中有 416 个可单独复位。馆主、会影响剧情通路或一次性奖励的目标，以及规则待核实的事件均禁用。新增 ROM 后，各版本的事件规则仍需逐项核对。
- **精灵能力**　PC 箱内的能力值是计算预览。取出精灵时，游戏根据其存档数据重新计算。队伍中手填的能力值也可能在升级或进化时被游戏重算。
- **运行环境**　发行包面向 Windows x64，目前已在 Windows 11 x64 完成验收。地图、字模和游戏数据在运行时从玩家选择的 ROM 中读取。

## 适配顺序

1. **原版红版多语言。** 先用日文版和英文版建立多 ROM 识别与存档读写，再逐批验证法文、德文、意大利文和西班牙文。重点检查名字编码与字节上限、PC 箱容量、存档偏移、校验和各语言的 ROM 数据表。 [日文原版红版官方资料](https://www.pokemon.co.jp/game/other/gb-rg/) · [任天堂公布的红版语言](https://www.nintendo.com/en-gb/Games/Game-Boy/Pokemon-Red-Version-266109.html)
2. **绿版。** 从日版原版开始。核对存档布局、野生遇敌表和道具数据，再按绿版的地图与脚本验证可复位目标。 [红版与绿版官方资料](https://www.pokemon.co.jp/game/other/gb-rg/)
3. **黄版。** 先验证基础存档编辑，再处理跟随皮卡丘的专属状态、地图与新增剧情。测试编辑后能继续游戏，且皮卡丘的跟随和互动仍正常。 [黄版官方资料](https://www.pokemon.co.jp/game/other/gb-pikachu/)
4. **蓝版。** 分别适配日版《青》和国际版 Pokémon Blue，按地区与修订版核对 ROM 数据、存档结构和事件脚本。 [日版《青》官方资料](https://www.pokemon.co.jp/game/other/gb-blue/) · [国际蓝版官方资料](https://www.nintendo.com/en-gb/Games/Game-Boy/Pokemon-Blue-Version-266054.html)

## 每个版本的验收

- 用 ROM 的 SHA-256 识别版本，将文字编码、存档布局和事件规则分别记录在版本配置里。界面显示识别到的语言与修订版，未知 ROM 不启用写入。
- 用该版本的新档和已有进度档测试队伍、精灵箱和道具的读写。测试游戏内重新载入和换箱、无更改往返的字节一致性、备份编号与还原，以及覆盖失败时保留原档。
- 单独验收地图和事件。以字节差异和模拟器复验确认复位只改目标所需的标记及校验值。发布时在兼容清单中分别标明存档编辑、地图浏览和事件复位的支持状态。
