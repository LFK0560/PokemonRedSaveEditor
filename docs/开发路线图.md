# 开发路线图

当前采用开放编辑、逐例修复的维护方式。国际版和日版存档、地图事件及直接标记编辑均已开放。认证用于记录已确认的范围，不作为功能开关。

## 优先事项

1. 保障保存和还原：维护自动日期备份、重复编号、覆盖前备份、原子写入及外部变更检测。
2. 优先处理用户反馈中的地图事件：对象编号、隐藏道具、战斗位、显隐、剧情工作状态及跨版本关联。
3. 补齐 ROM 资料定位：国际版不同语言与修订版、日版红绿蓝黄及汉化、改版的名称和地图表。无法定位时仍保留参考图和手工标记入口。
4. 将已确认的案例标记认证，并记录其 ROM 摘要、规则和适用范围。

## 当前局限

日版和国际版分别采用初代的两种 SRAM 布局；完全改变存档结构的改版需要单独适配。没有读取到 ROM 专用资料时，名称、种族能力、升级招式及地图事件关联使用通用参考，可能与具体改版不一致。

地图事件没有通用的「重玩整个剧情」指令。清除完成位后，游戏可能还检查奖励、显隐、传送或地图工作状态。关联均可修改，缺少规则时可以直接编辑全部剧情位。参考格网及对象坐标也可能需要根据用户的版本修正。

箱内能力在取出时重算，手填队伍能力可能在升级或进化时重算。发行目标为 Windows x64。新开放范围不宣称已经逐 ROM 或逐剧情验收；后续按具体反馈推进。
