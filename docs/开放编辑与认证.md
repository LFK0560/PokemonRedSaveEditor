# 开放编辑与认证

v1.2.0 采用开放编辑策略：认证记录表示已确认的具体资料，未认证不阻止导入、地图事件或标记编辑。存档可以独立打开，ROM 是名称和地图资料来源，程序不把哈希当作使用白名单。

## 认证的范围

原已核对的简体中文红版保留 ROM、地图资料及 416 条独立事件规则的认证。之前确认过的英文红、蓝、黄保留核心字段认证。各标记按对应资料显示，不意味着所有剧情状态、汉化补丁或其他地区修订版已确认，也不证明某个存档必然来自所选 ROM。

馆主、奖励和通路等原先禁用的事件现已开放，其说明继续显示；这些新开放操作不因同一 ROM 已认证而自动获得事件规则认证。用户自定义关联同样标为未认证。

## 未认证资料如何使用

能够定位 ROM 的地图表时读取实际地图头和对象；未能定位的楼层使用参考坐标及格网定位图。没有 ROM 也能浏览参考地图和编辑事件。格网不表示当前 ROM 的实际墙壁、通路或图块。

通用事件关联以原版地图 ID、对象 ID 和已分析的显隐或剧情位为参考。日版使用日版的存档基址；不同游戏的位含义、对象编号和脚本可能变化，所以这些关联仍为未认证。没有独立关联的对象可手工绑定，也可直接编辑剧情标记。

「事件标记」开放全部剧情位和相关工作区，不要求认证。复位只改变当前关联的位及校验。重战、领物、传送、徽章和剧情通路是否恢复，由游戏加载后的脚本处理；需要组合修改时，可补充关联或直接改位。

## 发布和维护

本轮按维护者要求不运行各版本兼容性和游戏流程测试，仅执行代码编译和发行打包检查。历史验收记录与新开放范围分开记录。后续优先根据可复现的用户反馈修复具体规则、名称、坐标和保存问题；确认过的案例补充认证范围。

反馈请使用 [兼容性问题模板](https://github.com/LFK0560/PokemonRedSaveEditor/issues/new?template=compatibility.md)，提供游戏颜色与语言、修改器版本、模拟器、目标地图和对象编号、操作前后表现。可附所选 ROM 的 SHA-256；没有 ROM 也可报告。
