# 验收记录

2026-11-15 在 Windows 11 x64（10.0.26200）测试 Windows 发行程序。精灵和地图控件的回归使用原生 Qt 窗口，游戏内回归使用 PyBoy 2.9.0 运行指定中文版 ROM。所有写入使用独立副本或本地新开档。

| 项目 | 实测结果 |
| --- | --- |
| Windows 启动与输入 | 双击发行程序，选择中文路径 ROM，依次打开闪电鸟复位前、复位后以及实机流程生成的「赤红」新开档。主区错误、箱区错误、文件长度和列表结束标记的拒绝用例通过。 |
| 队伍和精灵箱 | 在 Windows 界面向队伍、当前箱和其他箱添加精灵。已有精灵的等级与经验、10 字节中文昵称、HP、麻痹、4 个招式与各自 PP/提升次数、4 个个体值和 5 个努力值均经编辑并复读。手填原值保留，公式选项重算，箱内能力只读，队伍满员时原档数据一致。红字选项可写入，「挣扎」禁用。 |
| 道具 | 在 Windows 界面添加、替换、移除两处条目，验证每组 1–99、红字代币和禁用占位项。下游测试确认保存字段只改变目标列表和主校验。游戏内读到背包伤药 ×99 和 PC 精灵球 ×1。 |
| 新开档换箱 | 从游戏标题创建并保存新档。写入三处精灵后从标题选择「继续游戏」，在 PC 切到第 2 箱并触发游戏保存。验证第 1、2 箱的精灵、队伍和两处道具，重新启动游戏再读到相同结果。 |
| 地图与楼层 | 在 Windows 发行程序从城镇地图进入深灰市，拖动、滚轮缩放，从博物馆入口弹窗选 2F 并点击原位 NPC。界面回归确认小刚说明徽章副作用并禁用。「宝可梦屋」3F 和 B1F 的两个隐藏点坐标都是（1, 9），逐个点选只清当前楼层目标的位。 |
| 闪电鸟 | Windows 界面在发电厂原位点击并保存 `53:9`。输出与复位后样本逐字节相同。模拟器继续复位前、复位后两份档，从发电厂站位走到（4, 8）朝（4, 9）确认。复位后进入 50 级闪电鸟战斗，对照档无战斗。 |
| 急冻鸟与超梦 | 在双子岛 B4F 和华蓝洞窟 B1F 的独立副本预置已完成状态，分别继续复位前、复位后的档。复位后在原位触发急冻鸟 50 级、超梦 70 级的战斗。 |
| 普通训练家 | 将测试副本的玩家放在 11 号道路目标 2 附近，以两份档分别继续。复位档可对战，打赢后经验与金钱增加，训练家完成位置位，对照档保持已打状态。 |
| 可见与隐藏拾取 | 发电厂（7, 25）的速度增强剂和（12, 1）的隐藏 PP 提升剂各测试一次。复位时两处物品列表完全一致，经原位拾取后背包对应道具增加一份。隐藏项的已拾取标记在独立测试副本中预置。 |
| 读取校验与事件范围 | 226 张地图均解析渲染，416 个可操作目标逐项测试只清指定掩码，重复复位时字节一致。队伍、箱子、背包和道具差异均核对目标区域，跨箱首次写入核对初始化和校验。 |
| 文件和备份 | 无修改原地保存保持字节和文件时间戳，无修改另存逐字节一致。并发导入 6 次得到当天目录的 6 份独立备份。覆盖前备份完整，另存还原逐字节一致。测试写入拒绝和同一文件被持有写句柄，均保留磁盘原档及内存编辑。外部更新后的覆盖被拒绝。 |

## 2026-11-26 国际版兼容测试

v1.1.0-beta.1 使用从上游源码构建的原版 ROM，英文红、蓝、黄同时核对了上游摘要。英文三版完成了模拟器内新建与保存，随后在编辑器中添加队伍及当前、其他箱的精灵，编辑背包和 PC 道具，并从游戏的继续选项重新读取。三个版本均读到正确的队伍、当前箱与两处道具。测试同时比较了修改区域、无修改往返、覆盖前备份、重复导入编号及黄版专属状态区域。

法、德、意、西的红蓝版共 8 份 ROM 通过数据表定位和单字节名字编码检查，构造存档的编辑、复读和备份测试通过。这 8 份 ROM 的完整游戏流程和其他语言的黄版仍待社区反馈。国际版地图与事件适配状态见 [兼容说明](国际版兼容.md)。

从最终 Windows ZIP 解压后运行 EXE，使用中文路径的英文黄版 ROM 与游戏内生成的 `.sav`，完成导入、添加精灵和保存。两份日期目录中的导入及覆盖前备份均与原档逐字节一致；输出存档通过校验且保留黄版专属状态区域。界面正确显示国际版地图与事件待适配提示。
