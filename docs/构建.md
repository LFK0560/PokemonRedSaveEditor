# 源码构建与回归

在 Windows x64 安装 Python 3.13，然后在项目根目录打开 PowerShell。构建使用已固定的 Pillow、PySide6 Essentials 和 PyInstaller。首次安装依赖需要可用的包源，运行编辑器全程使用本地文件。

```powershell
python -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
$env:Path = "${PWD}\.venv\Scripts;$env:Path"
& .\build.ps1
```

构建后，`dist/PokemonRedSaveEditor/PokemonRedSaveEditor.exe` 可以运行。该目录及 Windows ZIP 中的 `_internal` 需要与程序同在。Windows ZIP、源码 ZIP 和 SHA-256 清单均在 `dist`。直接调试窗口可使用 `python main.py`。

## 在本地复验

将前三个变量改为本机对应的 ROM 和原始样本路径。测试从原始样本读入，每个写入测试在独立的输出路径或临时目录完成。PyBoy 会在指定输出目录生成测试存档与截图。

```powershell
$rom = 'D:/Games/PokemonRed/K 口袋妖怪红[简].gb'
$before = 'D:/Games/PokemonRed/复位前.srm.bak'
$after = 'D:/Games/PokemonRed/复位后.srm'
$fresh = 'work/游戏验收/新开档[赤红].srm'
$env:PYTHONIOENCODING = 'utf-8'
python tests/emulator.py $rom $before $after 'work/游戏验收'
python tests/regression.py $rom $before $after $fresh
python tests/gui.py $rom $before $after $fresh
python tools/export_events.py $rom 'docs/事件索引.csv'
```

`editor/save.py` 实现 SRAM 解析、校验及有限范围的更新。`editor/files.py` 实现初始备份、覆盖前备份、文件变更检测和写入。`editor/rom.py`、`editor/charset.py`、`editor/maps.py` 与 `editor/events.py` 使用原版数据和地址。Qt 窗口通过这些模块提供编辑操作。

`editor/map_index.json` 含地图 ID、名称和楼层分组。若需重建，用 `python tools/build_map_index.py 本地参考仓库目录` 读取指定提交的地图常量。ROM 偏移、原版地图和游戏内行为取自支持的中文版。下面分别是 SRAM、能力值与取出精灵流程的对照源码。
