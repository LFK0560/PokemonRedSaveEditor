# 国际版存档兼容

国际版红、蓝、黄可以共用本程序的核心存档读写。v1.1.0-beta.1 已移除单一 ROM 哈希白名单的入口限制，使用 ROM 文件头和实际数据表识别英文、法文、德文、意大利文及西班牙文版本。可编辑队伍、12 个精灵箱、背包及 PC 道具，接受 32 KiB 的 `.srm` 和 `.sav`。本轮先处理国际版。

## 存档布局对比

以下字段在国际版红、蓝、黄中相同，偏移从 SRAM 文件开头计算。

| 字段 | 三者共用的布局 |
| --- | --- |
| 文件大小 | 32,768 字节 |
| 玩家名 | `0x2598`，占 11 字节 |
| 背包 | `0x25C9`，20 组 |
| PC 道具 | `0x27E6`，50 组 |
| 随身队伍 | `0x2F2C`，最多 6 只 |
| 当前精灵箱 | `0x30C0` |
| 精灵箱容量 | 12 箱，每箱 20 只 |
| 单只精灵记录 | 队伍 44 字节，箱内 33 字节，另存名字 |
| 其余箱子 | `0x4000` 和 `0x6000` 起的两个区，每区 6 箱 |
| 主校验 | `0x3523`，对 `0x2598` 至 `0x3523` 前的字节累加后取反 |

这些共同字段可直接复用读写逻辑。黄版另有皮卡丘亲密度等专属状态，本次编辑只更新所选记录及相关校验。 [红蓝 SRAM 定义](https://github.com/pret/pokered/blob/a7b6c19e3b5c2d169abeacfe0e28047993872342/ram/sram.asm) · [黄版 SRAM 定义](https://github.com/pret/pokeyellow/blob/b452f2ab07185075140061c5084ab866d5e4a794/ram/sram.asm) · [PKHeX 的国际版字段偏移](https://github.com/kwsch/PKHeX/blob/a5311f9f55a84376fd2e2499b25d9fb9640d9f2d/PKHeX.Core/Saves/Substructures/Gen12/SAV1Offsets.cs)

## ROM 数据与文字

精灵、招式和道具的名称仍从玩家选择的 ROM 读取。不同语言的重音字母和部分符号编码有差异，国际版昵称最多 10 个单字节字符。名字和招式表在 ROM 中的位置也有变化。例如英文红版的种类名称表在 `0x1C21E`，英文黄版在 `0xE8000`。兼容模式按表的内容定位，并读取对应的成长曲线、升级招式及学习器资料。

地图对象和事件脚本需要按 ROM 适配。当前地图复位使用已核实的简体中文红版脚本，国际版兼容模式的地图页显示待适配状态。存档编辑已可独立使用。

## 测试和反馈

英文红、蓝、黄已完成模拟器内新建存档、编辑后继续游戏、精灵与道具读取，以及备份写入的基本验证。法、德、意、西四种语言的红蓝版完成了实际 ROM 数据表识别及构造存档的读写、备份回归。各地区修订版、其他语言的黄版和完整流程仍需要用户反馈。

兼容模式会保留文件尺寸、列表边界和存档校验检查。每次成功导入自动生成带日期的原档备份，重复导入自动编号，覆盖前另存备份。反馈时请提供游戏颜色、语言、ROM 的 SHA-256、模拟器、复现步骤及报错文字。将鼠标放到程序的 ROM 信息栏可查看哈希。 [提交兼容性问题](https://github.com/LFK0560/PokemonRedSaveEditor/issues/new?template=compatibility.md)
