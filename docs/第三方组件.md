# 第三方组件

Windows 发行包使用 PySide6 Essentials、Shiboken6 与 Qt 6.12.0 动态库。Qt / Qt for Python 的开源条款见 [LGPL-3.0](licenses/LGPL-3.0.txt) 和 [GPL-3.0](licenses/GPL-3.0.txt)。可使用 ABI 兼容的修改版动态库替换独立的 Qt DLL、Qt 插件和 Python 扩展，或用源码和构建脚本重新打包。Qt 及 Qt for Python 由 The Qt Company Ltd. 和贡献者开发。 [Qt 许可说明](https://doc.qt.io/qt-6/licensing.html) · [Qt for Python 许可](https://doc.qt.io/qtforpython-6/licenses.html)

对应组件源代码可从上游获取。

- [Qt Base 6.12.0](https://download.qt.io/official_releases/qt/6.12/6.12.0/submodules/qtbase-everywhere-src-6.12.0.zip)
- [Qt SVG 6.12.0](https://download.qt.io/official_releases/qt/6.12/6.12.0/submodules/qtsvg-everywhere-src-6.12.0.zip)
- [Qt Image Formats 6.12.0](https://download.qt.io/official_releases/qt/6.12/6.12.0/submodules/qtimageformats-everywhere-src-6.12.0.zip)
- [PySide6 与 Shiboken6 源码](https://download.qt.io/official_releases/QtForPython/pyside6/PySide6-6.12.0-src/pyside-setup-everywhere-src-6.12.0.zip)

发行包 `docs/licenses` 同时包含 Python、Pillow 和 PyInstaller 的分发许可。PyBoy 仅用于从源码运行验收。
