# 使用说明

## 选择 ROM 和存档

将发行 ZIP 完整解压，在 Windows x64 中运行 `PokemonRedSaveEditor.exe`。第一次打开，先选 `K 口袋妖怪红[简].gb`。同一内容可放在任意目录并重命名。程序接受 SHA-256 为以下值的 ROM。

```text
F4092C50B04A0C471C8E1CDA4AF1551AC451C754BE8AE03F86430C9C0DC0E073
```

点「导入存档」选择游戏内「保存」生成的 32 KiB SRAM（`.srm`），也可直接打开本工具的备份或同格式的 `.srm.bak`。遇到尺寸、主区校验、箱区校验或结构错误时，程序会显示具体原因。导入和保存支持中文路径。

## 编辑随身队伍、精灵箱和道具

- 在「队伍与精灵箱」选定位置，点「添加精灵」，或双击已有精灵。右侧选择框标出当前箱，容量栏显示已用及剩余空间。第一次向从未换箱的存档写入其他箱子时，程序会初始化其余箱子。
- 等级修改会同步计算经验。昵称最多 10 个游戏编码字节，通常可用 5 个汉字。四项个体值的最低位决定 HP 个体值。五项努力值以初代的 Stat Exp 表示，初代共用单一「特殊」能力。
- 编辑已有队伍精灵时默认显示保存的五项能力值。新增精灵默认按公式预览能力。可选「原值 / 手填」，也可用「按游戏公式重算」应用计算值。升级、进化、使用能力增强剂、取出箱内精灵等操作可能触发游戏重算。程序检查当前 HP 与最大 HP，并限制可能在重算时溢出的手填组合。
- 箱内精灵有当前 HP、等级、努力值和个体值。五项能力值为只读预览，游戏取出时会根据经验与这些字段计算。
- 红字选项表示按已核实的本作常规途径无法取得，但可以写入。黄褐色表示来源待验证，例如部分外部版本、活动或跨版本交换组合。禁用项会说明原因。招式需从第一格连续填写，每个招式的 PP 受该招式及 PP 提升次数约束。
- 在「道具」选「背包」或「PC 道具储存处」，可添加、编辑、替换或移除条目。背包 20 组，PC 50 组，每组 1–99。关键道具和秘传学习器只允许一份，移除可能中断通路的最后一份时会提示。与已核对任务相关的道具会显示道具状态和剧情旗标状态。

## 在地图上复位单个目标

在「地图与事件」查看城镇地图，点击地点进入详细地图。按住左键拖动，滚轮缩放。蓝色方框是入口或传送点，多层区域会弹出楼层选择，也可在楼层图内点「选择楼层」。可用下拉框选地图，用「存档位置」跳到玩家所在地图，或在右侧搜索目标名称或编号，例如 `53:9`。

点击目标原位的标记后，可看到地图 ID、对象 ID 或隐藏事件索引及当前状态。允许复位且标为「已完成」时，点「复位此事件」，随后保存。游戏中的重战收益和拾取由原脚本结算。灰绿 NPC 标记中的「可重复互动」可直接在游戏中交谈。馆主、通路机关和待验证的脚本会显示具体禁用理由。

## 保存、编号和还原

- 每次成功导入均创建原档的逐字节备份，例如 `备份/2026-11-15/冒险.srm`、`备份/2026-11-15/冒险_2.srm`。目录按 Windows 当地日期创建，已有文件继续保留。扩展名 `.srm.bak` 会完整保留。
- 「查看改动」可查看待保存操作和从上次保存起变化的字节数。实际覆盖前，程序再备份磁盘上的旧内容，例如 `冒险_覆盖前.srm`。
- 写入失败或模拟器从外部更新原档时，窗口会显示原因并保留待保存编辑。关掉模拟器对同一文件的写入后可重试。原档已经更新时，可把编辑「另存为」另一个文件。
- 还原时先关闭模拟器，在程序中导入所需日期的备份，点「另存为」保存到模拟器使用的路径。若目标文件存在，确认后会先复制旧内容，再覆盖目标。也可以关闭模拟器后在资源管理器中复制备份到目标位置。
