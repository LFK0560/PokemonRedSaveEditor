# 口袋妖怪红存档修改器

Windows x64 离线工具。编辑初代存档的地图事件、队伍、精灵箱、背包和 PC 道具。v1.2.0 开放国际版及日版布局，ROM 可选，认证仅为提示，未认证版本也可以使用地图事件和标记编辑。

## 快速开始

1. 从 [v1.2.0 发行页](https://github.com/LFK0560/PokemonRedSaveEditor/releases/tag/v1.2.0) 下载 `PokemonRedSaveEditor_Windows_x64.zip`，完整解压后运行 EXE。
2. 关闭模拟器，直接点「导入存档」，选择游戏内保存生成的 32 KiB `.srm`、`.sav` 或其 `.bak`。程序按存档内容识别国际版或日版布局。
3. 可选「选择 ROM」读取地图及名称资料。切换 ROM 保留当前存档和待保存改动。
4. 在「地图与事件」选择目标并复位；可用「关联标记」调整偏移，或点「事件标记」直接编辑剧情位。点「保存」或「另存为」写入。

## 备份和认证

- 每次成功导入，原档自动放入存档旁的 `备份/YYYY-MM-DD/`；同名依次添加 `_2`、`_3`。覆盖前另存 `_覆盖前` 备份，保留原子写入、写后复读和外部文件变更检查。
- `✓ 已认证` 表示已有证据的具体 ROM 数据或事件规则。未认证项目同样开放。认证不表示存档和 ROM 必然属于同一版本。
- 没有选 ROM 或某版本的数据表尚未定位时，使用参考名称、地图坐标和事件关联；格网表示参考定位图。未认证关联可能需要按用户反馈修正，可自行编辑。
- 日版为 8 箱、每箱 30 只，昵称最多 5 字节；国际版为 12 箱、每箱 20 只，昵称最多 10 字节。两种布局独立处理。
- 馆主、奖励、显隐和通路可能由多个状态共同控制。界面保留影响说明，并开放复位及手工标记编辑。初次修改可先另存副本。
