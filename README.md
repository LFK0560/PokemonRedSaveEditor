# 口袋妖怪红存档修改器

适用于指定《口袋妖怪红》简体中文版的 Windows x64 离线存档编辑器。可编辑随身队伍、12 个精灵箱、背包和 PC 道具，在原版地图上查看目标并逐个复位已核实的事件。

## 快速开始

1. 在 [GitHub Releases](https://github.com/LFK0560/PokemonRedSaveEditor/releases/latest) 下载 `PokemonRedSaveEditor_Windows_x64.zip`。完整解压后双击 `PokemonRedSaveEditor.exe`。
2. 点「选择 ROM」，选取自己准备的 `K 口袋妖怪红[简].gb`。点「导入存档」，选取游戏内保存生成的 `.srm`。
3. 在「队伍与精灵箱」或「道具」中应用编辑，或在「地图与事件」中点选目标并复位。点「保存」或「另存为」把改动写入文件。

## 注意事项

- 仅支持 [使用说明所列 SHA-256](docs/使用说明.md#选择-rom-和存档) 对应的简体中文版 ROM 和 32 KiB SRAM 存档。ROM 与存档由玩家自行提供。
- 写入前请关闭正在使用该存档的模拟器，避免模拟器随后把旧内容写回。初次编辑可用「另存为」生成一份副本。
- 每次成功导入都会把原档放进存档旁的 `备份/YYYY-MM-DD/`。当天同名备份依次添加 `_2`、`_3` 等编号。覆盖保存前另有一份 `_覆盖前` 备份，可从「查看备份」找到。
- 仅可复位已核实能独立恢复的目标。道馆馆主和会影响剧情通路的事件在地图上显示禁用原因。
